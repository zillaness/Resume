Uploading through the browser

  1. Open the repo, navigate into the site/ folder.
  2. Add file → Upload files, then drag your HTML in named index.html.
  3. Commit. The deploy workflow runs on push and the live page updates in about a minute.

Or from a terminal

cp /path/to/your-portfolio.html site/index.html
git add site && git commit -m "Add portfolio page"
git push
GitHub blocks any single file over 100 MB, and warns above 50 MB. If your HTML is that large it's almost certainly base64-embedded images or video — pull those out into site/assets/ and reference them by filename. The page will also load far faster.
